`ion_extra` extends `ion_web` with typed request parsing and response serialization.

## Installation

```yaml
dependencies:
  ion_extra: ^0.2.0
```

## Minimal Example

```dart
import 'package:ion_extra/ion_extra.dart';
import 'package:ion_router/ion_router.dart';
import 'package:ion_web/ion_web.dart';

class CreateUserDto {
  CreateUserDto.fromJson(JsonObject json)
      : name  = json.string('name', rules: [.length(min: 2)]),
        email = json.string('email', rules: [.email()]);

  final String name;
  final String email;
}

final app = Router();

app.post('/users', (req) async {
  final dto = await req.json(CreateUserDto.fromJson);
  return RawJson({'name': dto.name, 'email': dto.email}, status: .created);
});
```
