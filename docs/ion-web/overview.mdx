`ion_web` is the foundation of the ion ecosystem. It handles TCP socket management, HTTP/1.1 request parsing, response writing, and protocol upgrades (WebSocket, SSE, multipart).

## Installation

```yaml
dependencies:
  ion_web: ^0.1.0
```

## What's Included

| Component | Description |
| --- | --- |
| `IonServer` | HTTP/1.1 server with configurable timeouts, connection limits, and graceful shutdown |
| `Request` | Stream-based request object with typed headers and request-scoped context |
| `Response` | Builders for text, bytes, streams, files, redirects, SSE, and WebSocket upgrades |
| `WebSocket` | Native WebSocket upgrade with origin validation and sub-protocol negotiation |
| `SSE` | Server-Sent Events response builder for streaming text and JSON events |
| `Multipart` | Stream-based multipart parser with memory-to-disk spooling |

## Minimal Example

```dart
import 'package:ion_web/ion_web.dart';

Future<void> main() async {
  final server = await IonServer.serve(
    (req) => .text('Hello World'),
    address: .loopbackIPv4,
    port: 8080,
  );

  print('Server listening on http://${server.address.host}:${server.port}');
}
```

`Handler` is a typedef for `FutureOr<Response> Function(Request req)`. Any function or callable object matching this signature can be passed to `IonServer.serve()`.
